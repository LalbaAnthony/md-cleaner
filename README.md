# MD Cleaner

[![npm](https://img.shields.io/npm/v/@lalba-anthony/md-cleaner.svg)](https://www.npmjs.com/package/@lalba-anthony/md-cleaner)

Cleans up Markdown files by removing AI fingerprints.

## Usage

```sh
npx @lalba-anthony/md-cleaner my-file.md
```

Flags: `-h, --help`, `-v, --version`.
